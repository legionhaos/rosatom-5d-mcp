# STE AI 3D/5D Print Assistant — инструкция по установке и настройке

## 1. Требования
- STE Slicer (форк Cura 3.6), выданный организаторами. Внешние pip-пакеты **не нужны**.
- Доступ к OpenAI-совместимому API: **Base URL**, **API Key**, **название модели**
  (модель должна поддерживать `tools`/function calling; для анализа картинок — vision).

## 2. Установка
1. Закройте STE Slicer.
2. Скопируйте папку `plugin/` целиком в каталог плагинов STE Slicer и переименуйте её в **`STEAIAssistant`**.
   Итоговая структура: `<plugins>/STEAIAssistant/plugin.json`, `__init__.py`, `agent/`, `ui/`, …
   Каталог плагинов зависит от сборки; обычно это папка `plugins` внутри каталога установки
   или в пользовательской папке данных STE Slicer (`%APPDATA%\ste_slicer\...` на Windows,
   `~/.local/share/ste_slicer/...` на Linux). Самый надёжный способ найти его —
   **Справка → Показать папку конфигурации** и подняться в соседнюю `plugins`.
3. Запустите STE Slicer. Плагин загрузится автоматически.
4. В меню **Расширения → STE AI Помощник** должны появиться пункты
   «Открыть ИИ-чат» и «Настройки LLM API».

Автоматически: `python setup.py install_plugin --target "<каталог plugins>"` (из корня репозитория).

## 3. Настройка подключения к LLM
Меню **Расширения → STE AI Помощник → Настройки LLM API**:

| Поле | Пример | Примечание |
|------|--------|-----------|
| API Base URL | `https://api.example.com/v1` | Без `/chat/completions` в конце |
| API Key | `sk-...` | Хранится в Preferences STE Slicer, в логах маскируется |
| Модель | `gpt-4o-mini` | Имя из документации провайдера |

Нажмите «Проверить соединение». Альтернатива UI — переменные окружения (используются, если в UI пусто):
`STE_LLM_URL`, `STE_LLM_KEY`, `STE_LLM_MODEL`, а также `STE_AI_RESULTS_DIR` — папка для результатов.

## 4. Использование
1. Откройте чат, прикрепите STL/3MF (кнопка 📎 или перетаскиванием); при желании — фото/эскиз с направлением нагрузки.
2. Опишите задачу: например, *«Кронштейн под нагрузку, PETG, без поддержек»*.
3. Следите за шагами агента в панели логов: анализ геометрии → выбор 3D/5D и материала → ориентация и параметры → слайсинг → проверка.
4. Прочитайте инженерное обоснование в чате. Модель на сцене уже настроена и нарезана.
5. Кнопка «Экспортировать результат» сохраняет `results/<model_name>/project.3mf`, `result.gcode` и `chat_N.png`.

## 5. Где лежат результаты и логи
- Результаты: папка из настройки/`STE_AI_RESULTS_DIR`, по умолчанию `~/STE_AI_results/<model_name>/`.
  Для сдачи скопируйте содержимое в `results/` репозитория и выполните `python setup.py check_results`.
- Лог плагина: `ste_ai_assistant.log` рядом с плагином (если папка недоступна для записи — `~/.ste_ai_assistant/`).
- Аудит MCP-вызовов: `ste_ai_mcp_audit.jsonl` в той же папке (ключи API маскируются).

## 6. Устранение неполадок
| Симптом | Что делать |
|---------|-----------|
| Плагин не появился в меню | Проверьте имя папки `STEAIAssistant` и наличие `plugin.json` в её корне; смотрите лог STE Slicer (`cura.log`) на ошибки импорта |
| «LLM_CONNECTION_ERROR» | Проверьте URL (с `/v1`), ключ, доступ в сеть/прокси, нажмите «Проверить соединение» |
| Ошибка 429/5xx | Клиент делает автоповторы; подождите или смените модель |
| «SLICING_FAILED» | Модель не помещается на стол или нет нужного профиля; агент попробует повернуть/уменьшить модель, либо сделайте это вручную |
| «PROFILE_NOT_FOUND» | Нужный материал/режим отсутствует в сборке — выберите из списка, который покажет агент |
| Файлы не попали в results/ | Проверьте права на запись в папку результатов |

## 7. Для разработчиков
Структура и ответственность — в корневом `README.md`. Внутри слайсера любые обращения к сцене и
стекам настроек должны идти через `MainThreadDispatcher` (иначе возможны падения Qt).
