# results/

Для каждой тестовой модели — отдельная папка `results/<model_name>/`:

```
results/<model_name>/
├── project.3mf      # проект STE Slicer (сцена, режим 3D/5D, материал, параметры)
├── result.gcode     # G-code после слайсинга
└── chat_1.png       # скриншот диалога с обоснованием (можно chat_2.png, ...)
```

Создаётся автоматически кнопкой «Экспортировать результат» (`ArtifactExporter.export_all_for_model`).
Проверка перед сдачей: `python setup.py check_results`.
